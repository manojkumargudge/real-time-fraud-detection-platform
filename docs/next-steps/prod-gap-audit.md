this project now (stated, with the reason). Within each category rows are ranked by value per
hour. Effort is for one person on this laptop, including tests and docs, excluding CI wait.

**Invalidates?** says which existing evidence or documented numbers would have to be re-measured
or reworded after the fix. "No" means the fix only adds to them.
